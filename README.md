# Training App

Privates Projekt. Einfacher Trainings-Tracker im Browser.

## Starten

`index.html` im Browser öffnen. Keine Installation nötig.

## Funktionen

- Sätze erfassen (Übung, Gewicht, Wiederholungen)
- Wochenübersicht
- Verlauf mit Löschen
- Daten bleiben lokal im Browser (localStorage)
